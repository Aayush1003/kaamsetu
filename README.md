# KaamSetu

KaamSetu is an AI-powered local work marketplace that helps workers discover nearby jobs and helps businesses hire reliable local talent faster.

## What this project is

This repository contains a polished landing page for KaamSetu, showcasing the product vision and business opportunity. The concept focuses on:

- workers finding trusted local jobs
- businesses hiring fast without unreliable referrals
- AI-driven matching based on skills, proximity, and trust
- a scalable marketplace model for local work categories

## Run locally

Open `index.html` in a browser, or serve the folder with a simple local server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Files

- `index.html` — landing page structure
- `style.css` — responsive styling and layout
- `script.js` — small interactions for mobile menu and footer year

## Ideal business use case

KaamSetu is designed for categories like:

- plumbing
- electrical work
- house cleaning
- repair services
- drivers and delivery
- construction helpers
- maintenance services

The page is built to present a credible MVP and can evolve into a full product with authentication, job listings, AI matching, and payments.
